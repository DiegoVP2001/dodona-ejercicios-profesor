# Acceso premium

Un servicio de streaming desbloquea contenido premium cuando el usuario lleva 3 meses o más suscrito.

Lee la cantidad de meses que lleva suscrito el usuario e imprime si tiene acceso premium.

**Nota:** usa `input()` sin texto de prompt.

**Ejemplo:**
```
3
```
```
¿Tienes acceso premium? True
```

**Contenidos:** int, input, comparacion, print

## Ejemplo

**Entrada**
```text
3
```

**Salida esperada**
```text
¿Tienes acceso premium? True
```
