# Transferencia bancaria

Un banco permite transferir dinero solo si el saldo disponible es de al menos $5.000 **y** la cuenta está verificada.

Lee el saldo (número entero) y si la cuenta está verificada (`si` o `no`). Imprime si la transferencia es posible.

**Nota:** usa `input()` sin texto de prompt.

**Ejemplo:**
```
5000
si
```
```
¿Puedes transferir? True
```

**Contenidos:** int, input, and, comparacion, print
