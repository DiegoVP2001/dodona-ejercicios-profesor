# Tarifa del bus

El cobro de un bus aplica tarifa TNE ($490) **solo si** el pasajero tiene tarjeta de estudiante vigente **y** el recorrido es dentro de la región. Cualquier otro caso paga tarifa normal ($810).

Lee si el pasajero tiene TNE (`si` o `no`) y si el recorrido es regional (`si` o `no`). Imprime el monto a pagar.

**Nota:** usa `input()` sin texto de prompt.

**Ejemplo:**
```
si
si
```
```
Tarifa a pagar: $490
```

**Contenidos:** input, if, else, and, comparacion-string, print
