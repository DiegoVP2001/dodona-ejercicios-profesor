# Stand en la Feria de Isla de Maipo

Cada temporada, la Feria de Emprendedores de Isla de Maipo habilita nuevos puestos para vendedores locales. Para poder inscribir un stand, el emprendedor debe tener su ficha municipal al día (`si` o `no`) y además que queden puestos disponibles (un número mayor a 0).

Lee si la ficha está al día y cuántos puestos quedan. Imprime si puede inscribir su stand. No uses texto de prompt en `input()`.
