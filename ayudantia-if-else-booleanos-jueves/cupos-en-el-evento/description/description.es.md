# Cupos en el evento

Un evento tiene entradas disponibles si la cantidad vendida aún no alcanza el aforo máximo.

Lee cuántas entradas se han vendido y cuál es el aforo del evento.

- Si hay cupo: imprime `¡Entrada confirmada! Nos vemos en el evento.`
- Si no hay cupo: imprime `Sin entradas disponibles. Quedaste en lista de espera.`

**Nota:** usa `input()` sin texto de prompt.

**Ejemplo:**
```
150
200
```
```
¡Entrada confirmada! Nos vemos en el evento.
```

**Contenidos:** int, input, if, else, comparacion, print

## Ejemplo

**Entrada**
```text
150
200
```

**Salida esperada**
