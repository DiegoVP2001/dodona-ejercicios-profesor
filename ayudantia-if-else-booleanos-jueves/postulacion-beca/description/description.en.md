# Postulación a beca

Una beca escolar exige promedio ≥ 80 (escala 0–100) **y** asistencia ≥ 85%.

Lee el promedio y la asistencia del estudiante (ambos como números enteros).

- Si cumple ambas condiciones: imprime `Cumples los requisitos. ¡Puedes postular a la beca!`
- Si no cumple: imprime `No cumples los requisitos. Revisa tu promedio o asistencia.`

**Nota:** usa `input()` sin texto de prompt.

**Ejemplo:**
```
85
90
```
```
Cumples los requisitos. ¡Puedes postular a la beca!
```

**Contenidos:** int, input, if, else, and, comparacion, print
