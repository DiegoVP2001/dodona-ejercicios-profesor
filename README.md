# Dodona ejercicios profesor

Repositorio de ejercicios Python para Dodona.

## Flujo local

1. Generar propuestas desde el repo de clases.
2. Crear ejercicios Dodona con TESTed.
3. Validar estructura localmente.
4. Hacer commit y push a GitHub.
5. El webhook avisa a Dodona para sincronizar los cambios.

No subir notebooks, PPTs ni material interno de clases a este repositorio.
